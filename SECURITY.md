# Security

If you find a security problem in this SDK or in the Vaartix API, please report it privately:

- **GitHub:** [report a vulnerability](https://github.com/vaartix-mail/vaartix-python/security/advisories/new) (private
  vulnerability reporting), or
- **Email:** **security@vaartix.com**

Please don't open a public issue. We reply within 2 working days and will credit you if you like once
it's fixed.

Never include real API keys or webhook secrets in reports, issues, pull requests or emails.
